# 룽룽씨 메이커

AI 채팅에서 OOC로 출력한 **문자 내역**과 **메모장**을, 실제 휴대폰 화면처럼 보기 좋게 시각화해서
PNG로 저장하는 웹앱입니다.

👉 **https://sammongsalmon.github.io/rungrungchat/**

---

## 무엇을 하나요

붙여넣기 한 번이면 OOC 지시문·하단 메타정보·`<details>` 블록을 자동으로 걸러내고,
말풍선 / 메모 단위로 쪼개서 폰 화면으로 그려 줍니다.

| | |
|---|---|
| **채팅 탭** | 카카오톡·iMessage를 참고한 대화방. 참가자 조합으로 대화방을 자동 분리하고(단톡 포함), 잘못 보낸 문자는 실제 수신자 방에 “잘못 보냄” 뱃지로 표시합니다. |
| **메모 탭** | 아이폰 메모 리스트 / 갤럭시 카드 / 2단 그리드 3가지 홈 스타일. 카드를 누르면 해당 메모 상세로 들어갑니다. |

## 기능

- **범위 지정** — 양끝 슬라이더로 “몇 번째부터 몇 번째까지” 뽑을지 정하고, 항목별 체크박스로 골라냅니다.
- **수정 · 삭제** — 보낸 사람 / 시간 / 본문을 직접 고치고, 복제·순서 변경·삭제가 됩니다. 굵게·기울임·취소선·크기 버튼 포함.
- **자동 저장** — 원본·편집·테마·설정이 브라우저에 자동 저장돼서, 창을 닫았다 열어도 그대로 이어집니다.
- **HTML 스타일 그대로** — `**굵게**`, `*기울임*`, `~~취소선~~`, `<small>`, `<big>`, `<span style="font-size:…">`,
  `<font size>` 를 인식합니다. 그 외 태그는 화이트리스트 방식으로 전부 무력화되므로 붙여넣기가 안전합니다.
- **단톡 지원** — `받는사람 : 쿠베라, 아미타바` 처럼 여러 명이면 단톡방으로 인식하고 상단바에 인원수를 표시합니다.
  인물이 3명 이상이면 **한 방만 / 방마다 한 장 / 단톡으로 합치기** 중에서 고를 수 있습니다.
- **읽음 · 안 읽음** — 기본은 읽음이고, 마지막으로 보낸 메시지 아래에 문구가 붙습니다(문구 변경·끄기 가능).
  안 읽음은 메시지마다 지정하며, 단톡이면 안 읽은 인원 수까지 넣을 수 있습니다.
- **N장 분할** — 슬라이더로 장수를 정하면 **보낸 사람 셀 단위**로 잘라 **높이가 정확히 같은** PNG 여러 장을 만듭니다.
  한 사람의 말풍선 묶음은 절대 중간에서 끊기지 않습니다.
- **플립 모드** — 선택한 장이 가운데 크게, 앞뒤 장이 투명하게 깔리는 3D 전환. 스와이프·화살표키로 넘깁니다.
- **PNG 저장** — 파일 이름을 직접 정하거나 비워두면 자동 지정. 1× / 2× / 3× 해상도.
- **테마 51종 + 직접 제작** — 색 미리보기 칩을 누르면 바로 적용. 만든 테마는 저장·내보내기(`.rrtheme.json`)·불러오기가 됩니다.
- **색 직접 고르기** — 지금 적용된 테마의 색(말풍선·배경·강조)이 그대로 올라옵니다. 색을 바꾸면 화면의 **색 배치는 그대로 둔 채 색만 갈아 끼우고**, 어느 색이 어느 자리에 들어갈지는 버튼 하나로 섞을 수 있습니다.
  색을 새로 만드는 게 아니라 자리만 바꾸므로 고른 색은 사라지지 않고, 어떤 조합이 나와도 대비는 자동으로 맞춰집니다.
- **컬러 피커** — HSV 평면 + 색상 띠 + HEX + RGB/HSL 값, 그리고 **그 색이 얹힐 바탕과의 대비를 실시간으로** 보여줍니다.
- **배경 그라데이션 자동 계산** — 끝 색은 손으로 고르는 게 아니라 배경색과 테마 강조색에서 파생됩니다. 직접 바꾸면 자동이 풀리고, 버튼으로 다시 켭니다.
- **가독성 자동 보정** — 색을 직접 바꿔 대비가 떨어지면 경고가 뜨고, 한 번에 고칠 수 있습니다.
- **글자 크기 지정** — 메시지 / 이름 / 시간 / 상단바 / 메모 제목 / 목록 제목 / 부제 크기를 각각 조절합니다.
- **패널 크기 조절** — 패널과 미리보기 사이 손잡이를 끌어 넓이(높이)를 바꾸고, 더블클릭하면 기본값으로 돌아갑니다.

## 만듦새

- **의존성 0, 파일 1개.** 프레임워크도 CDN 스크립트도 쓰지 않습니다. `index.html` 하나만 있으면 오프라인에서도 돕니다.
- **PNG 내보내기**는 `html2canvas` 같은 라이브러리 대신 `DOM → 인라인 스타일 → SVG foreignObject → canvas`
  경로를 직접 구현했습니다. SVG 기준으로 래스터화되므로 2×·3×에서도 글자가 벡터처럼 선명하고,
  **미리보기에 보이는 것이 그대로 저장**됩니다.
- **폰 미리보기는 시스템 폰트**(Apple SD Gothic Neo / Noto Sans KR)를 씁니다. 실제 카톡·메모 앱이 그렇고,
  웹폰트를 쓰지 않아야 저장 결과가 화면과 100% 일치합니다. 앱 UI만 Pretendard를 쓰되 실패하면 조용히 폴백합니다.
- **조작감** — 슬라이더는 포인터 캡처로 잡아서 손을 뗀 자리에 마커가 그대로 남고, 드래그 중에는 DOM을 다시 만들지
  않습니다. 입력창은 포커스가 있는 동안 값을 되쓰지 않아 타이핑 중 글자가 사라지지 않습니다.
- 모바일 세로·가로, 태블릿, 데스크톱 레이아웃을 각각 대응하고 다크 모드를 지원합니다.
- 아이콘은 128px PNG를 데이터 URI로 심어 파비콘과 브랜드 마크가 같은 바이트를 씁니다. 외부 이미지 파일이 없습니다.

## 개발

배포되는 건 루트의 `index.html` 하나입니다. 편집은 `src/` 조각들에서 하고 빌드로 합칩니다.

```bash
python3 build.py     # src/*  ->  index.html
```

```
src/
  00_head.html      <head> · 디자인 토큰
  01~05 *.css       레이아웃 / 패널 / 컨트롤 / 폰 화면 / 반응형
  06_body.html      마크업
  10_util.js        유틸 · 아이콘 · 색 · HTML 샌디타이저
  11_parse.js       채팅 · 메모 파서
  12_theme.js       테마 엔진 + 기본 테마
  13_state.js       상태 · 자동저장
  14_render.js      폰 화면 렌더러
  15_controls.js    슬라이더 · 입력창 · 토스트
  16_export.js      장수 분할 · PNG 내보내기
  17_app.js         덱 구성 · 레이아웃 · 파싱 파이프라인
  18_edit.js        범위 · 편집 리스트
  19_themeui.js     테마 UI
  20_init.js        샘플 데이터 · 배선 · 부팅
```

> `src/14_render.js` 의 폰 화면 렌더러에는 **의사 요소(`::before` / `::after`)를 쓰지 않습니다.**
> PNG 내보내기가 DOM을 복제해서 SVG로 직렬화하기 때문에, 의사 요소로 그린 것은 저장된 이미지에서 사라집니다.
> 말풍선 꼬리처럼 장식으로 보이는 것도 전부 실제 노드(inline SVG)로 그려져 있습니다.

`Screenshot_*.jpg` 는 팔레트 테마의 출처가 된 참고 이미지입니다.
